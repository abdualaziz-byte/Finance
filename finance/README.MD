# CS50 Finance

A web application that simulates a stock exchange platform. Users can register, log in, browse stock prices, buy and sell stocks, add funds, and view their portfolio and transaction history.

## Features

- User registration and login
- Stock price lookup
- Buy and sell stocks
- Add funds to an account
- Portfolio tracking
- Transaction history
- Password hashing and session-based authentication

## Technologies

- **Python**
- **Flask**
- **SQLite / SQL**
- **HTML**
- **Jinja Templates**
- **Bootstrap**
- **CS50 Library**

## About the Project

This project heavily demonstrates the use of **SQL databases** and **Flask with Python** to build a dynamic web application.

It also uses **Jinja templates** to dynamically display information from the backend in HTML pages.
